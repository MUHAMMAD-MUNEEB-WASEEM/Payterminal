## Understanding the Payment Flow

### Current Architecture:

```
┌─────────────────────────────────────┐
│   CUSTOMER FILLS CARD FORM          │
│   (Browser - PublicInvoice.jsx)     │
└──────────────┬──────────────────────┘
               │
               ↓
┌─────────────────────────────────────┐
│   OPTION 1: WITH COLLECT.JS         │
│   (Recommended - PCI Safe)          │
│                                     │
│   1. Collect.js detects form       │
│   2. Card stays in browser         │
│   3. Token generated by NMI        │
│   4. Token sent to backend         │
└──────────────┬──────────────────────┘
               │ Token (safe)
               ↓
┌─────────────────────────────────────┐
│   BACKEND RECEIVES TOKEN            │
│   + Reads security_key from DB      │
│   Posts to NMI:                     │
│   {                                 │
│     security_key: "..."             │
│     payment_token: "..."            │
│   }                                 │
└──────────────┬──────────────────────┘
               │
               ↓
┌─────────────────────────────────────┐
│   NMI API: secure.nmi.com           │
│   Validates security_key            │
│   Processes token                   │
│   Returns response                  │
└──────────────┬──────────────────────┘
               │ Success/Failure
               ↓
         Result shown to user
```

### ⚠️ Error Scenarios

#### 1. Network Error
**Log:**
```
❌ Request error: connect ECONNREFUSED
```
**Meaning**: Can't reach NMI API
**Fix**: Check internet connection, verify firewall allows HTTPS

#### 2. Token Error
**Log:**
```
❌ Missing NMI security_key
```
**Meaning**: Merchant credentials not set properly
**Fix**: Run `node setup-nmi-credentials.js` again

#### 3. TLS Certificate Error
**Log:**
```
❌ Hostname/IP does not match certificate's altnames
```
**Meaning**: Wrong endpoint being used
**Fix**: Make sure code uses `https://secure.nmi.com/api/transact.php`

## Troubleshooting

### Issue 1: Collect.js Not Loading

**Symptom**: Card form appears but Collect.js doesn't initialize

**Check in Browser Console (F12):**
```javascript
// Check if CollectJS is available
window.CollectJS

// Should return: function CollectJS(...)
// If undefined: Collect.js script didn't load
```

**Fix:**
1. Refresh page
2. Check browser console for errors
3. Verify merchant has tokenizationKey in database

---

### Issue 2: Backend Not Receiving Token

**Symptom**: Payment fails with "No payment data provided"

**Log:**
```
❌ No payment data provided
```

**Check:**
1. Is token being generated by Collect.js?
2. Is token being sent to backend?
3. Check browser Network tab (F12) for POST request

---

### Issue 3: Still Getting Authentication Error

**Symptom**: "Authentication failed - Invalid API Key or Secret"

**Means**: 
- Either security_key is incorrect
- Or NMI API is rejecting the credentials for this merchant

**Solutions:**
1. Verify setup ran: `node setup-nmi-credentials.js`
2. Check merchant database directly
3. Contact NMI support with specific error from logs

## Important Notes

### Why Collect.js?
- ✅ Card data never leaves browser
- ✅ Your servers never see card details
- ✅ NMI handles tokenization securely
- ✅ PCI compliance is automatic
- ✅ Supports all major card types

### Why security_key?
- ✅ Simpler than API Key/Secret combo
- ✅ Native NMI method
- ✅ Directly supports tokenized payments
- ✅ Better error messages

### Why NMI endpoint?
- ✅ BeyondBancard uses NMI backend
- ✅ Using NMI directly is more reliable
- ✅ Better support and documentation
- ✅ Faster payments

## What to Do If It Fails

1. **Check logs first**:
   ```bash
   tail -f backend/logs/nmi-payment.log
   ```

2. **Note the error code** from response

3. **Common error codes**:
   - `AUTH_FAILED`: Wrong security_key
   - `PAYMENT_DECLINED`: Card declined
   - `NETWORK_ERROR`: Can't reach NMI
   - `UNKNOWN_RESPONSE`: Unexpected response format

4. **Gather information**:
   - Full error message from logs
   - Timestamp of failure
   - Test card used
   - Transaction amount

5. **Next debugging step**:
   - Create detailed error report
   - Contact NMI support with error details
   - Include timestamp and transaction details
